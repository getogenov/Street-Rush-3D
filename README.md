# Street Rush 3D

Простая одиночная 3D-аркадная гонка для браузера.

## Возможности

- 3D-машина и ночный город
- трафик с несколькими типами машин
- ускорение и торможение
- столкновения
- таймер и скорость
- перезапуск гонки
- управление Windows/ПК с клавиатуры
- экранное управление на iOS/Android
- адаптация под мобильный экран
- режим полного скрытия интерфейса

## Управление

### Windows / ПК
- W / ↑ — газ
- S / ↓ — тормоз
- A / ← — влево
- D / → — вправо
- Space — тормоз
- H — скрыть/показать интерфейс

### iOS / Android
Используй экранные кнопки внизу.

### Режим без интерфейса

Нажми `◐` или клавишу `H`.
Интерфейс полностью исчезнет. На мобильном устройстве нажми в левом верхнем углу, чтобы вернуть его.

## GitHub Pages

1. Создай новый репозиторий.
2. Загрузи `index.html`, `style.css`, `game.js`, `README.md` в корень.
3. Открой Settings → Pages.
4. Выбери `Deploy from a branch`.
5. Выбери ветку `main` и папку `/ (root)`.
6. Нажми Save.

Через некоторое время GitHub выдаст ссылку на игру.

## Технологии

HTML + CSS + JavaScript + Three.js.

Three.js загружается из jsDelivr, поэтому при первом запуске нужен интернет.
